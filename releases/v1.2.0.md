# v1.2.0

Автоматическое заполнение факта при выполнении и отдельный учёт проваленных событий.

- При выборе **«Выполнено»** пустое фактическое время заполняется по актуальному времени события. Уже записанный факт сохраняется; его можно исправить в карточке. Для событий на весь день время автоматически не заполняется.
- **«Частично»** без факта попадает в список **«Ожидают фактического времени»** в аналитике. Откройте событие из этого списка и укажите фактический интервал.
- Добавлены статусы **«Провалено · ассистент»** и **«Провалено · директор»**. Выбирайте их, если событие не состоялось из-за указанного участника, например, если он забыл о встрече. Для согласованной отмены используйте «Отменено»; подробности можно записать в комментарии.
- В аналитике появились отдельные карточки отмен и провалов, разбивка провалов по участнику, фильтры событий, дневные счётчики и столбцы CSV. Учитываются также события на днях без фиксации плана. Провалы не добавляют часы работы и не считаются выполненными.
- После удаления или отмены события в Mail.ru локально выбранная причина провала сохраняется без лишнего предупреждения о пропаже. Исходный план и история остаются доступными.

Отмены и провалы относятся к дате исходного плана, а если его нет — к актуальной дате события. Ночные события учитываются один раз. Фильтр контролируемых категорий действует и на новые показатели.

Существующие записи при обновлении не получают выдуманный факт: автозаполнение выполняется при сохранении выбранного статуса «Выполнено». Ранее выполненные события без времени остаются в списке ожидающих заполнения.

Скачайте `DirectorCalendar-1.2.0-Setup-x64.exe`, закройте календарь и запустите установщик от обычного пользователя Windows. В версии 1.1.0 установщик также доступен через **Настройки → Обновления приложения → Проверить обновления**. Данные, исходные планы, история, резервные копии и сохранённые учётные данные сохраняются. Для переносного варианта распакуйте весь `DirectorCalendar-1.2.0-portable-x64.zip` в отдельную папку.

Windows 10/11 x64. Установщик пока без цифровой подписи. Перед публикацией обязательны полные проверки Windows/Linux и проверка дистрибутива с обновлением с опубликованной версии 1.1.0, включая новую логику статусов и оба способа восстановления копии.
