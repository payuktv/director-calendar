# v1.7.1

- The update window now shows the new version, the version you have and the download size together. Release notes have a more readable layout in both light and dark themes.
- During a download, reopen the window from the update icon to see its progress. When the package is ready, the calendar offers to restart and install it.

## Что нового

- В новом окне обновления сразу видны новая и установленная версии, а также размер загрузки. Список изменений стало удобнее читать в светлой и тёмной темах.
- Пока обновление скачивается, нажми на значок обновления, чтобы увидеть прогресс в процентах. Когда всё готово, календарь предложит перезапустить приложение для установки.
