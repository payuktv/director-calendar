# v1.0.0

First stable release of Director Calendar for Windows x64, promoting the accepted v0.13.10 feature scope.

- Read-only Mail.ru synchronization with bounded, cancellable processing; recurring events and individual exceptions; consistent source-removal and local-cancellation behavior.
- Local events, original-plan fixation, execution status, actual time and comments; day/week/month analytics, CSV export and retained change history.
- Verified backups, normal and emergency recovery, safe update backups and preservation of existing data and credentials.
- Completed target-system acceptance on Windows 10 x64, including real-account synchronization, reopening, synthetic source-change scenarios, cancellation/retry and backup restoration. See the [acceptance record](https://github.com/payuktv/director-calendar/blob/v1.0.0/docs/ACCEPTANCE-v1.0.0.md).
- Retain mandatory full Windows/Linux tests and Windows distribution acceptance for this exact release commit. Stable publication marks the release as latest only after all uploaded attachments pass verification.

This promotion introduces no functional, database-schema or dependency changes from v0.13.10. The database schema remains version 4. The bundled runtime remains Python 3.14.10, Expat 2.10.0, SQLite 3.54.1 and OpenSSL 3.5.9.

## Install or update

Close Director Calendar, download `DirectorCalendar-1.0.0-Setup-x64.exe` from Assets and run it as your normal Windows user. Reopen the existing desktop or Start menu shortcut. Python and administrator privileges are not required. Existing compatible events, plan, actual time, history, settings and saved credentials are preserved; a verified backup is required before a different application version opens existing data. Installation remains manual.

For portable use, extract the entire `DirectorCalendar-1.0.0-portable-x64.zip` into a separate directory and keep the executable with `_internal`. Data remains in the existing AppData location; preserve any custom data-directory setting. Do not overlay runtime files from different versions.

## Known limits

The installer is unsigned. This is a single-user local application with one Mail.ru calendar; it never writes events to Mail.ru. Automatic application updates, periodic calendar polling and multi-PC synchronization are not included. Local databases and backups are not encrypted by the application. Target-system acceptance used an existing Windows 10 installation with a clean application data profile, not a freshly installed operating system; additional Windows/display coverage remains future work.

The release includes eight verified attachments: installer, portable ZIP, checksums, build and dependency information, distribution acceptance report, upgrade-source record and release manifest. GitHub's source-code archives are not installation packages.
