# v0.13.4

Bound the resources used by untrusted calendar recurrence expansion and allow synchronization to be cancelled safely.

- Fetch and parse calendar data in a disposable process with an OS-enforced 512 MiB memory ceiling, a 20-second CPU budget and a 60-second overall deadline, including network, recurrence expansion and serialization. If a limit cannot be installed or is exceeded, discard the entire snapshot.
- Consume recurrence results incrementally and stop at 20,000 instances. Retain process limits because the recurrence library also buffers internally. Enforce the existing 16 MiB input limit on direct parsing as well.
- Add Cancel update. Closing the main window cancels active synchronization and closes after its worker exits. Discard queued results after cancellation, including results emitted just before the worker finished.
- Preserve existing event identities, moved exceptions, all-day events, time zones, local records, frozen plans and history. A rejected or cancelled import does not apply any event changes.
- Validate the isolated worker inside the actual Windows bundle during distribution acceptance.

Close the application and install `DirectorCalendar-0.13.4-Setup-x64.exe`. The installed executable remains the network client, so existing VPN application exclusions continue to apply. This is an unsigned pre-release; installation remains manual.
