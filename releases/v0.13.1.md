# v0.13.1

Fix stale future Mail.ru events remaining in the unfrozen schedule after source deletion or replacement.

- After a complete successful sync, withdraw missing future events with no frozen plan, actual time, manual status or comment from the current schedule.
- Retain the event identity, category and history. If the source event reappears, restore the same record. Do not infer replacements from matching titles.
- Reconcile previously flagged missing events on the next complete sync. Partial responses, failures and periods outside the sync window never withdraw events.
- Keep past, frozen and locally protected events visible with a source warning.
- Show the withdrawn count in synchronization results and retain the old schedule times in History. Validate and restore backups containing withdrawn records.

Close the application and install `DirectorCalendar-0.13.1-Setup-x64.exe`, then use **Update from Mail.ru** for the affected dates. Only the loaded synchronization period is reconciled. Updates remain manual; the installer is unsigned. This remains a pre-release before v1.0.0 acceptance.
