# v0.13.9

- Reject malformed application records before normal restoration, emergency recovery and startup. Validation covers SQLite storage types, event/category text, numeric flags and tolerances, timestamps, synchronization records, sequences and bounded history JSON. Invalid copies leave the working database and journals unchanged; staged data is checked again before replacement.
- Preserve compatible older database formats, historical plain-text descriptions, deleted-event history, original plans and recorded facts. Startup also offers recovery when opening the database or constructing the main window fails, and disposes any incomplete window first.
- Update the bundled Expat XML parser from 2.9.0 to 2.10.0. Build both `pyexpat` and `_elementtree` from hash-verified official CPython/Expat sources and run the upstream XML regression suites. The system Python installation is unchanged; source builds require a C compiler (MSVC on Windows).
- Require the installed executable to reject malformed backup records and verify the paired XML modules, including the fixed empty-subparser case, before publication. Add regression tests for both restore modes, startup recovery, staging failures, source archive safety and publication gates.

Close the application and install `DirectorCalendar-0.13.9-Setup-x64.exe`. Installation remains manual; Python and the updated XML modules are bundled. The database schema remains version 4. Existing valid data and local backup preferences are preserved; logically invalid copies are rejected rather than silently converted.

This is an unsigned pre-release. CPython 3.14.10, SQLite 3.54.1, OpenSSL 3.5.9 and the calendar dependencies remain unchanged. Clean target-Windows and real-account acceptance are still required before v1.0.
