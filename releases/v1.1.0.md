# v1.1.0

Check for new Director Calendar versions directly from **Settings → Application updates → Check for updates**.

- Compare the installed version with the latest published stable GitHub release, without a GitHub account or access token.
- When an update is available, open its Windows installer or release notes in the default browser. Downloading and installation remain manual.
- Checks run only on request, keep the interface responsive and stop after 15 seconds or when the calendar closes. A failed check reports an error instead of claiming the application is up to date.
- Installer metadata now uses the neutral **Director Calendar** publisher. Existing application data and installation paths are preserved.

Calendar records and credentials are not sent when checking for updates. Drafts, pre-releases, incomplete installers and unexpected download addresses are rejected. The network backend is initialized only when a check is requested.

To update from v1.0.2 or earlier, download `DirectorCalendar-1.1.0-Setup-x64.exe` from this release, close Director Calendar and run the installer as your normal Windows user. Older versions do not have the new update panel, so this first update must be found through the Releases page. Existing events, fixed plans, history, backups and saved credentials are retained. For portable use, extract the complete `DirectorCalendar-1.1.0-portable-x64.zip` into a separate directory.

Windows 10/11 x64 is supported. The installer remains unsigned. Publication requires the complete Windows/Linux test suites and Windows distribution acceptance, including upgrade from the published v1.0.2 installer and HTTPS/TLS support in the packaged application.
