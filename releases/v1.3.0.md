# v1.3.0

Director Calendar can now download a new version while you work and open it the next time you start the calendar. Both the Windows installer edition and the portable edition use the published portable ZIP for subsequent updates.

- Automatic downloads are enabled in **Settings → Application updates**. The app checks at startup and once a day while open. Turn the option off to check and update manually from the same panel.
- Choose **Restart now** when the update is ready, or continue working and use the existing shortcut at your next launch. An open editor, synchronization or backup can finish before a restart.
- Before switching versions, the app checks the package size and SHA-256 against the official GitHub release and runs a startup check on the extracted copy. Your database, history and credentials stay in place. The existing backup runs before the new version opens your database.

**First upgrade from v1.2.0 or earlier.** Close the calendar and run `DirectorCalendar-1.3.0-Setup-x64.exe` once. The existing update panel in v1.1.0 and v1.2.0 provides the download. For portable use, extract the entire `DirectorCalendar-1.3.0-portable-x64.zip` into a writable folder. Future updates open from the same shortcut.

Windows 10/11 x64. The original installer version appears in Windows Installed Apps. Settings inside the calendar shows the running version. The installer remains unsigned.
