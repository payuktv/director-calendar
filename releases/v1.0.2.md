# v1.0.2

Refine the background of days with a fixed original plan:

- Light theme: a fresher, lighter pale green that remains unobtrusive.
- Dark theme: a subtle green tint with no increase in brightness over the ordinary calendar background.

Only the two theme colors change from v1.0.1. Calendar behavior, the database schema and dependencies remain unchanged. Native Windows previews were inspected in both themes. No additional local test run was requested for this color adjustment; the standard release workflow still requires full Windows/Linux tests and distribution acceptance before publishing this installer.

Close Director Calendar and run `DirectorCalendar-1.0.2-Setup-x64.exe` as your normal Windows user. Existing data, backups and credentials are preserved. Installation remains manual. For portable use, extract the complete `DirectorCalendar-1.0.2-portable-x64.zip` into a separate directory. The installer remains unsigned.
