# v0.13.5

Reduce build dependencies and distribution size while preserving installation and upgrade checks.

- Use PySide6 Essentials, which contains every Qt module used by the application and tests. Stop installing unused Addons, PDF and WebEngine packages and bundling their incidental plugins and libraries.
- Recreate the dedicated build environment when its dependency lock changes, preventing removed packages from leaking into subsequent builds. Record distribution sizes in build information and the CI summary.
- Test upgrades using the actual previous published installer instead of rebuilding that version. Verify its SHA-256, size, release manifest and source tag before use, and record the installer identity with the acceptance results. Download or verification failures stop the build.
- Retain full Windows/Linux release tests and native installation, startup, update, backup, credentials, uninstall and downgrade checks.

Close the application and install `DirectorCalendar-0.13.5-Setup-x64.exe`. This is an unsigned pre-release; installation remains manual.
