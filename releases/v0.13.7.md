# v0.13.7

- Updated the bundled interpreter from Python 3.13.17 to Python 3.14.10, including its security fixes and Expat 2.9.0. The separately verified SQLite 3.54.1 remains in the distribution.
- Pinned and hash-verified pip 26.3 for builds. Changing Python or dependency locks recreates the isolated build environment.
- Added mandatory checks of the actual Python, Expat and OpenSSL libraries loaded by the installed executable before a release can be published.
- Updates remove the exact obsolete Python 3.13 ABI files. Complete installed-file comparison still protects against leftover libraries while preserving user files, databases, backups and credentials.

The existing calendar dependencies remain on compatible versions; `python-dateutil` 4.x is not compatible with the current `recurring-ical-events` requirement. Calendar behavior and database format are unchanged.

Close the application and install `DirectorCalendar-0.13.7-Setup-x64.exe`. This is an unsigned pre-release; installation remains manual. Python does not need to be installed separately.
