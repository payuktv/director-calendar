# v0.12.1

First downloadable pre-release of Director Calendar. This is an evaluation build; v1.0.0 remains reserved for production acceptance.

## Changes

- Validate backup compatibility before normal and emergency restoration, using the same rules as startup.
- Reject newer database/application versions and malformed version records before replacing working data.
- Preserve support for compatible legacy backups and check staged files before migration and replacement.
- Recover from a damaged database at startup while preserving the original files separately.
- Provide a standalone Windows x64 installer and portable package with verified update/data-preservation checks.

## Install or update

Download `DirectorCalendar-0.12.1-Setup-x64.exe`, close Director Calendar and run the installer as your normal Windows user. Python and administrator privileges are not required. Existing events, original plans, actual work, history, settings and saved credentials remain in their existing locations.

For portable use, extract the entire `DirectorCalendar-0.12.1-portable-x64.zip`. Keep the executable and `_internal` together. The portable package also uses the existing AppData data directory.

`SHA256SUMS.txt` covers all attached distribution files. The acceptance report, upgrade-source record and release manifest identify the checked version and source commit.

## Known limitations

- The installer is not Authenticode-signed.
- Updates are installed manually. Real-account Mail.ru and clean target-Windows acceptance remain required before v1.0.0.
- This private repository requires authorized GitHub access to download the release.
