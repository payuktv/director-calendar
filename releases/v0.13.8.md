# v0.13.8

- Reject malformed settings before normal restoration, emergency recovery and startup, including invalid retention counts, time zones and last-backup records. A rejected copy leaves the original database and journals unchanged.
- Keep the current backup folder, automatic-copy preference and retention count during normal restoration. Emergency recovery uses the standard local backup folder with daily copies enabled and 30 retained copies. Imported backups cannot silently redirect future automatic copies.
- Reset the last-copy record after either restoration path so restored and newly added data receives a fresh backup. Original input files and safety/archive copies are preserved.
- Add regression tests for rejection before replacement, successful reopening, destination selection, inaccessible imported network paths and staged-file revalidation. The installed executable must also pass both new security checks before publication.

Close the application and install `DirectorCalendar-0.13.8-Setup-x64.exe`. Installation remains manual; Python is bundled. Existing calendar data and the database format are unchanged. After emergency recovery, select a different backup directory in Settings if required.

This is an unsigned pre-release. It includes the existing Python 3.14.10, SQLite 3.54.1 and compatible calendar dependencies.
