# v1.3.1

Windows automatic updates now continue on slow connections while bytes are arriving. A temporary interruption triggers up to three reconnection attempts. The app requests the remaining bytes and verifies the size and SHA-256 of the complete package before switching versions. Closing the calendar or cancelling the download still discards the unfinished package.

If you use v1.2.0 or earlier, install v1.3.1 once or extract its full portable ZIP. Future updates download in the background and take effect on the next launch. On v1.3.0, the existing updater can fetch this release. If its 15-minute limit interrupts the transition, use the v1.3.1 installer or portable ZIP once.
